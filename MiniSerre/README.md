# Mini-serre – Android natif (Kotlin + Jetpack Compose)
Tableau de bord Firebase Realtime Database (`/serre/live`, `/serre/control`, `/serre/history`) compatible avec le projet ESP32/Wokwi existant.

Build : poussez ce dossier à la racine d'un dépôt GitHub, puis Actions > Build Android APK > Run workflow, et téléchargez l'artefact `mini-serre-debug-apk`. Android 7.0+.
Le code n'a pas été compilé ni testé sur appareil dans cet environnement.
